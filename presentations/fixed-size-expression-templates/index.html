What an expression template is

An expression template does not do the arithmetic when you write it. It represents the computation — and it represents it as a type:

auto e = x * y + two * x;   // nothing is evaluated -- this builds a tree Add< Mul< Var, Var >, Mul< Const, Var > >

The structure is all in the type. So how many bytes does e need?

Safe — every node owns its children. Which also means it owns a copy.

… and it growshttps://godbolt.org/z/1qqo6Kra7lines 28–41 of 41

Size is O(nodes) — a real model is kilobytes of expression — and every operator+ copies the subtree it just built.

1// Children stored by reference: fixed size, but the temporaries are gone.2 3struct Var {4  double v;5  Var &operator=(double d) { v = d; return *this; }   // a variable can change6  double eval() const { return v; }7};8 9struct Const {10  double v;11  void operator=(double) = delete;                    // a constant cannot12  double eval() const { return v; }13};14 15template <class L, class R> struct Add {16  const L &lhs; const R &rhs;                         // 8 bytes each, whatever L and R are17  double eval() const { return lhs.eval() + rhs.eval(); }18};19 20template <class L, class R> struct Mul {21  const L &lhs; const R &rhs;22  double eval() const { return lhs.eval() * rhs.eval(); }23};24 25template <class L, class R> Add<L, R> operator+(const L &l, const R &r) { return {l, r}; }26template <class L, class R> Mul<L, R> operator*(const L &l, const R &r) { return {l, r}; }

A reference is 8 bytes whatever it points at.

exit code   gcc 15  -O0 → 20  ·  -O1 → 8  ·  -O2 → 0  ·  -O3 warns, at last     clang 18  20 at every level, silent.

A named subexpression outlives the temporaries it points at — right in debug, silently wrong in release.

Attempt 3 — the reference goes in the type (C++17)https://godbolt.org/z/TvajYG7EElines 1–29 of 47

Attempt 2 put the reference in the object. Put it in the type instead — the node has no members at all:

1// The reference moves into the type: the node stores nothing, so nothing can dangle.2 3struct Var {                               // unchanged: a variable you can assign to4  double v;5  constexpr Var &operator=(double d) { v = d; return *this; }6};7 8struct Const {                             // unchanged: it holds its value,9  double v;                                // and nothing can assign to it10  void operator=(double) = delete;11};12 13// C++17 made this leaf legal: `auto` template parameters, and a referenced object14// that only needs static storage duration -- no linkage, so a local static will do.15template <const auto &L> struct Ref {      // the reference is the type, not a member16  double eval() const { return L.v; }      // not constexpr: it reads a mutable object17};18 19template <class L, class R> struct Add {                        // no data members20  double eval() const { return L{}.eval() + R{}.eval(); }       // nor here: L and R are Refs21};22 23template <class L, class R> struct Mul {                        // no data members24  double eval() const { return L{}.eval() * R{}.eval(); }25};26 27template <class L, class R> constexpr Add<L, R> operator+(L, R) { return {}; }28template <class L, class R> constexpr Mul<L, R> operator*(L, R) { return {}; }

Nothing to copy, nothing to dangle.

… one byte, and it still evaluateshttps://godbolt.org/z/TvajYG7EElines 30–47 of 47

30int main() {31  static Var vx{2.0}, vy{3.0};             // the leaves live where you declared them32  static Const c2{2.0};33 34  constexpr Ref<vx> x;35  constexpr Ref<vy> y;36  constexpr Ref<c2> two;37 38  static_assert(sizeof(x) == 1);39  static_assert(sizeof(x * y) == 1);40  static_assert(sizeof(x * y + two * x) == 1);41  static_assert(sizeof(x * y + two * x + x * y) == 1);42 43  auto e = x * y + two * x;                // one byte, and it outlives every temporary44  if (e.eval() != 10.0) return 1;45  vx = 4.0;46  return int(e.eval());                    // 20: the same one-byte object, the new value47}

One byte, no lifetime, and it still reads the live variable. But the 2 arrives as Ref<c2>: the type records where the value lives, not what it is, so the compiler cannot fold it.

… and the constant's value too (C++20)https://godbolt.org/z/va3P4W185lines 1–28 of 43

1// C++20 finished the job: a double is a template parameter too, so the constant2// needs no object for a Ref to point at.3 4struct Var {                               // untouched -- still a variable, still 8 bytes5  double v;6  constexpr Var &operator=(double d) { v = d; return *this; }7};8 9// A Ref still reads a mutable object, so its eval() still cannot be constexpr.10template <const auto &L> struct Ref {11  double eval() const { return L.v; }12};13 14template <double V> struct Const {15  constexpr double eval() const { return V; }   // no object to read: this folds16};17 18template <class L, class R> struct Add {19  constexpr double eval() const { return L{}.eval() + R{}.eval(); }20};21 22template <class L, class R> struct Mul {23  constexpr double eval() const { return L{}.eval() * R{}.eval(); }24};25 26template <class L, class R> constexpr Add<L, R> operator+(L, R) { return {}; }27template <class L, class R> constexpr Mul<L, R> operator*(L, R) { return {}; }

C++20 takes a double as a template parameter, so the 2 needs no object to point at.

… and the 2 costs nothing eitherhttps://godbolt.org/z/va3P4W185lines 29–43 of 43

29int main() {30  static Var vx{2.0}, vy{3.0};             // only the variables need an object now31 32  constexpr Ref<vx> x;33  constexpr Ref<vy> y;34  constexpr Const<2.0> two;                // nothing to refer to: the value is the type35 36  static_assert(sizeof(two) == 1);37  static_assert(sizeof(x * y + two * x) == 1);38  static_assert((two * two).eval() == 4.0);  // constants alone fold at compile time39 40  if ((x * y + two * x).eval() != 10.0) return 1;41  vx = 4.0;42  return int((x * y + two * x).eval());      // 20, from an expression that stores nothing43}

One byte for the whole expression, still reading the live variable — and the part that needs no variable is constexpr, so it folds before the program runs.

The trade

Gained

✓no lifetimes

✓no copies

✓no size

✓a fully inspectable tree

Paid

✗an instantiation per expression

✗leaves must be objects with static storage duration
